# บ้านใบตอง — Static Restaurant Booking Website

เว็บไซต์ร้านอาหารไทยแบบ Static จำนวน 4 หน้า สร้างด้วย HTML, CSS และ JavaScript ธรรมดา ไม่ใช้ฐานข้อมูล ไม่ต้องมี Backend และไม่มีขั้นตอน Build

## หน้าเว็บไซต์
- `index.html` — หน้าแรก / แนะนำร้าน / เมนูแนะนำ
- `menu.html` — รายการอาหารและตัวกรองหมวดหมู่
- `booking.html` — แบบฟอร์มจองโต๊ะ / แสดงรายการ / ยกเลิกการจอง
- `about.html` — เรื่องราวร้าน / จุดเด่น / ข้อมูลติดต่อ

## ฟีเจอร์
- Responsive รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์
- เมนูนำทางทุกหน้า พร้อมเมนูมือถือ
- ค้นดูเมนูตามหมวดหมู่
- ฟอร์มจองโต๊ะ: ชื่อ เบอร์โทร จำนวนคน วันที่ เวลา และหมายเหตุ
- ตรวจสอบข้อมูลและไม่อนุญาตให้เลือกวันที่ย้อนหลัง
- เก็บรายการจองใน `localStorage` ของเบราว์เซอร์
- ดูรายการจองและยกเลิกได้
- ไม่ต้องติดตั้งแพ็กเกจหรือฐานข้อมูล

## ทดลองใช้งานในเครื่อง
เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรือใช้ VS Code Extension: Live Server

## Deploy ขึ้น Vercel
1. แตกไฟล์ ZIP นี้
2. สร้าง Repository ใหม่บน GitHub แล้วอัปโหลดไฟล์และโฟลเดอร์ทั้งหมด โดยให้ `index.html` อยู่ที่ root
3. เข้า https://vercel.com/new และเลือก Import Git Repository
4. เลือก Repository นี้
5. ตั้งค่า Framework Preset เป็น **Other**
6. Build Command: เว้นว่าง
7. Output Directory: `.` (จุด)
8. กด Deploy

หรือใช้ Vercel CLI:
```bash
npm i -g vercel
vercel
```

## ข้อจำกัดสำคัญ
เว็บไซต์นี้เป็น Static Demo: ข้อมูลการจองถูกเก็บเฉพาะใน `localStorage` ของอุปกรณ์และเบราว์เซอร์ที่ใช้กรอกเท่านั้น ไม่ได้ส่งถึงร้าน ไม่สามารถเห็นการจองข้ามอุปกรณ์หรือผู้ใช้ และไม่ใช่ระบบยืนยันการจองจริง หากต้องการใช้งานจริงต้องเพิ่ม Backend/API หรือบริการจัดเก็บข้อมูลภายหลัง

ชื่อร้าน ที่อยู่ เบอร์โทร ราคา และรูปภาพเป็นข้อมูลตัวอย่าง สามารถแก้ไขในไฟล์ HTML ได้
